# NATO Phonetic Alphabet Converter

Programa simples em Python que converte qualquer palavra para o **alfabeto fonético NATO**, utilizando um ficheiro CSV como fonte de dados. Cada letra introduzida pelo utilizador é traduzida para o respetivo código fonético.

---

## 🧩 Funcionalidade

- Lê um ficheiro CSV com o alfabeto fonético NATO.  
- Constrói um dicionário a partir dos dados.  
- Solicita uma palavra ao utilizador.  
- Converte cada letra no código fonético correspondente.  
- Valida a entrada e identifica caracteres inválidos.

---

## ▶️ Exemplo de utilização

**Input:**  
```
Word: hello
```

**Output:**  
```
NATO phonetic code: hello ['Hotel', 'Echo', 'Lima', 'Lima', 'Oscar']
```
